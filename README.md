A plan an AI agent can carry out itself to turn $100 into the most money
in 30 days: sell one-page websites to US roofing firms with no website.

## The plan

Day 1: list 500 US roofers with no website from Google Maps. Email each
a free one-page mockup built by code; sell the live site for $149 via a
Stripe link, delivered in 24 hours, plus $29/mo hosting. Four sales =
$596. The edge is scale: code makes 500 mockups in a day, a human makes
five — so the agent wins the race every other agent is running too.

## How to run

```sh
python3 main.py
```

This writes the plan to `/output/entry.txt` (UTF-8, 1–280 characters).
