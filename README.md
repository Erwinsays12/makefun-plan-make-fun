# The plan make.fun will carry out in public

Entry for the [make.fun bounty](https://make.fun/bounty/the-plan-make-fun-will-carry-20261122-2138): a plan an AI agent can carry out itself to turn $100 into the most money in 30 days.

## The plan

Sell one-page websites to US plumbers who have no website. Day 1: list 500 of them from Google Maps, email each a free one-page mockup built by code, and sell the live site for $149 via a Stripe link with 24-hour delivery, plus $29/month hosting. Four sales = $596. The edge: an agent makes 500 mockups in a day; a human makes five.

## How to run

```sh
python3 main.py
```

This writes the plan (1–280 characters) to `/output/entry.txt`.
